SEO and AI discovery
====================
Primary domain: https://kunalsk.com/

The build generates metadata and structured data from the portfolio content, then prerenders the React page. Adding a project still requires only a JSON file. Coming-soon projects are excluded from completed-work structured data. The UI stays unchanged.

Run `npm run build` to generate the AI files, metadata, and static HTML. Run `node scripts/check-seo.mjs` after building to validate the output. `index.html`, `public/robots.txt`, and `public/sitemap.xml` are generated by scripts/generate-seo.mjs; edit the generator rather than those outputs.

Launch steps:
1. Deploy this build to the existing Vercel project. Its vercel.json redirects kunalkaushik.vercel.app and www.kunalsk.com to kunalsk.com, preserving paths. Attach and verify kunalsk.com in Vercel before deployment so the redirect destination works.
2. Verify kunalsk.com in Google Search Console (a Domain property uses a DNS TXT verification record). The existing HTML verification token is preserved, but may belong to the older property. Submit https://kunalsk.com/sitemap.xml and request indexing for the homepage.
3. Add the canonical site to Bing Webmaster Tools, or import the verified Search Console property.
4. Set the website link on LinkedIn and GitHub to https://kunalsk.com/. Consistent identity links help distinguish you from others with the same name.
5. Check indexing and branded-name impressions in Search Console after deployment. Check redirects and the canonical returned by Google's URL Inspection tool.

The existing /ai/, /llms.txt and /llms-full.txt contain factual source-linked information with absolute canonical URLs. robots.txt allows crawlers. AI files are a convenience; they do not guarantee citation or AI-search inclusion. Google states that normal SEO foundations apply to AI features and that no special AI files are required.

Broad phrases such as "electrical engineer" are competitive. This portfolio focuses on the accurate identity "Kunal Kaushik", UIUC electrical engineering, robotics, embedded systems, PCB design and computer vision. It makes no unsupported claim of licensure, employment, availability, or completed coming-soon work.
